# Documented exploratory sequence feature set

Generated by `build_documented_features.py` from `data/Information_for_Baris_corrected.xlsx` (sheet `Information for feeding`, rows 5–36). It writes `documented_sequence_features.csv` (one row per signal peptide) and `documented_feature_dictionary.csv` (definitions and limitations). Re-run with:

```bash
python ouput/analysis/build_documented_features.py
```

Dependencies present in the run environment: pandas, numpy, Biopython, ViennaRNA Python bindings. ViennaRNA software/package version is embedded in the feature output. If ViennaRNA is unavailable, RNA-fold columns are missing rather than silently substituted.

## AA regions and physicochemical descriptors

The sequences have no verified cleavage-site or domain annotations. Thus regions are explicitly positional conventions, not inferred biological partitions:

- **N5:** first five listed amino acids (`aa[:5]`). N5 K/R count and fraction are recorded.
- **Heuristic core:** Python slice `aa[4:-3]`: positions 5 through L−3 inclusive in 1-based terms. This is a convenient central segment, **not** a claimed H-region. It is summarized by `AVILMFWY` hydrophobic-residue fraction, mean Kyte–Doolittle hydropathy, G/S fraction and S/T fraction.
- **C5:** final five listed residues (`aa[-5:]`). The output includes the literal subsequence and an indicator for an A-x-A pattern in the final three residues. This is only a pattern scan, not a cleavage-site annotation.
- Whole-sequence descriptors: length; hydrophobic-residue fraction using `AVILMFWY`; mean Kyte–Doolittle scale; `K+R−D−E` side-chain charge proxy and per-residue value; N/Q/S/T, G/S, S/T, proline, and cysteine composition fractions.

The charge proxy uses integer counts, ignores termini and pH-dependent partial charges, and is not pI. Kyte–Doolittle values are conventional residue hydropathy scores; the mean is a descriptive average, not a membrane partition energy.

## Nucleotide and RNA-fold descriptors

Only the listed signal-peptide coding sequence (CDS) is available. No verified RBS, 5′ UTR, start junction, downstream coding sequence, or terminator is included in the feature calculation. Recorded metrics are first-15-nt GC fraction (corresponds to N5 codons), first-30-nt GC and A/T fractions, first-30-nt CpG dinucleotide count, and whole-CDS GC fraction. No codon adaptation index is calculated because the host reference/codon-use data and construct context are unspecified; no RBS/accessibility metric is calculated because no verified RBS sequence is supplied.

RNA minimum free energy (MFE; kcal/mol) is computed using the ViennaRNA Python `RNA.fold` function with default parameters after T→U conversion, on (a) the full listed SP CDS and (b) fixed first 30, 45, and 60 nt windows. These are **truncated CDS-only sequence proxies**, not full-transcript initiation-region energies. Fixed windows provide a more comparable length basis than full-CDS MFE, but do not include RNA context outside those windows. MFE is dependent on sequence window, model parameters, and software version. It is not a measured structure, translation rate, or secretion mechanism. Negative MFE values indicate predicted favorable folding under that model, not a positive biological outcome.

## Input QC and known discrepancy

All 32 nucleotide strings are A/C/G/T and length exactly 3× the listed AA sequence. Translation in the standard frame agrees for 31/32. **SP31 is discrepant:** the listed DNA sequence translates as `MRKSLITLGLASVIGTSSFLIPFTSKTASA`, while the listed AA begins `VRKSLITLGLASVIGTSSFLIPFTSKTASA`. Both source strings are preserved and the mismatch is flagged; no correction is assumed. Confirm against construct records before using SP31 nucleotide-derived features. This differs from an earlier QC statement that reported all 32 matched; that earlier check was erroneous and should be superseded by this documented check.

## Intended downstream use

Features are candidates for a predeclared exploratory ML analysis—not evidence selected as biologically causal. Avoid high-dimensional sequence models with n=32. Use one outcome summary per unique peptide, keep blots separate or explicitly model block (not pool values as a common scale without justification), split/resample at peptide level, compare to a simple baseline, and report uncertainty. Replicate rows must not appear on both sides of a validation split. Evaluate performance only within the available range and do not treat it as validated generalization or synthetic-sequence design performance.
